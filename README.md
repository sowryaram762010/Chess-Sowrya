# Stockfish.js files

This folder contains the unmodified Stockfish.js 19.0.1 lite single-thread browser engine from the [v19.0.1 release](https://github.com/nmrugg/stockfish.js/releases/tag/v19.0.1):

- `stockfish-19-lite-single.js`
- `stockfish-19-lite-single.wasm`
- `Copying.txt` (GPL version 3 license)

The corresponding Stockfish.js source is available at [nmrugg/stockfish.js, tag v19.0.1](https://github.com/nmrugg/stockfish.js/tree/v19.0.1). The upstream chess engine source is [official-stockfish/Stockfish](https://github.com/official-stockfish/Stockfish), tag `sf_19`. Sow Chess starts the engine in a separate browser worker and sends it UCI text commands.
